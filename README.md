# 1초 (OneSecond)

여러 동영상에서 포인트를 찍으면 포인트 앞뒤 0.5초(총 1초)씩 잘라 하나의 영상으로 이어 붙여 주는 안드로이드 앱.

## 결정 사항
- 출력: 인스타 릴스 기본 (9:16, 1080x1920), 가로 영상은 꽉 채우기(crop)
- 소리: 원본 유지
- 클립 길이: 1초 고정
- 스택: Kotlin, Jetpack Compose, Media3 (ExoPlayer + Transformer), minSdk 26

## 화면 흐름
1. 영상 선택 (포토피커 다중 선택)
2. 포인트 지정 (영상별, 복수 가능)
3. 클립 순서 편집 (드래그 정렬, 삭제, 미리보기)
4. 내보내기 (MediaStore 저장, 인스타 공유)

## 개발 단계
1. MVP: 선택 → 포인트 1개씩 → 이어 붙여 저장
2. 영상당 포인트 여러 개 + 타임라인 마커 + 미세 조정
3. 클립 순서 변경, 삭제, 미리보기
4. 공유, 오류 처리, 다듬기
5. 실기기(S26) 테스트
